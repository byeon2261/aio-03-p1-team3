이 저장소에서 작업하는 Claude와 팀원이 같은 배경을 알고 시작하기 위한 문서입니다.
상황이 바뀌면(작업 완료, 일정·범위 변경) 이 파일을 PR로 고쳐 최신 상태로 유지합니다. 마지막 갱신: 2026-10-18.

## 1. 과제 개요

- 교과목: 웹 서비스 기초 및 AI 백엔드 개발 · 과제: 단위 프로젝트 1 (팀 3)
- 프로젝트 주제: **실시간 로그 대시보드 인터페이스** — AI 서비스의 동작을 로그로 확인하고, 사용자 피드백으로 답변을 개선한다.
- 목표
  1. 백엔드·DB·UI 통합 아키텍처를 구현하고 배포한다.
  2. 실시간 데이터 스트리밍으로 로그를 전달하고 시각화 대시보드를 만든다.
  3. 사용자 피드백을 바탕으로 AI 답변 품질과 서비스를 개선한다.
- 필수 산출물: **API 설계 문서, 화면 설계서, 데이터베이스 설계서, 배포된 대시보드**, 그리고 발표 PPT. 설계 문서는 최종 구현과 일치해야 한다.

### 최소 구현 범위 (과제 기준)

- 사용자 입력을 받고 AI 응답을 제공한다.
- 서비스 데이터를 DB에 저장하고 조회한다.
- 실제 요청의 로그를 수집하고 실시간으로 대시보드에 전달한다.
- 로그를 조건으로 조회하고 표·차트로 시각화한다.
- 답변에 연결된 사용자 피드백을 저장하고 확인한다.
- 피드백을 반영한 개선 전후를 같은 기준으로 비교한다.
- 배포 환경에서 위 흐름을 시연한다. 운영 화면과 로그 API는 허용된 사용자만 접근한다.

### 설계 문서 요구사항 (과제 기준)

- **API 설계 문서**: 리소스 중심 URL과 GET·POST·PUT·DELETE의 일관된 사용, 요청·응답 Pydantic 모델의 필수·선택 필드·타입·예시값, 중첩 JSON은 nested 모델로, 오류 응답은 HTTP 상태 코드·에러 코드·메시지·상세 정보로 표준화, 4xx(요청·인증)와 5xx(서버) 처리 규칙, 없는 리소스·잘못된 입력·인증 실패·서버 오류 예시.
- **화면 설계서**: 와이어프레임, 화면과 이동 관계(IA: 메인·상세·입력·설정·오류 화면), 버튼·입력폼·테이블·차트의 색상·폰트·여백 공통 기준, 사용자 액션(클릭·필터·새로고침 등)별 상태 변화·API 호출·로딩·성공·실패 피드백, 로그인 실패·빈 목록·요청 실패 상태.
- **데이터베이스 설계서**: 논리 ERD(엔티티·속성·관계·카디널리티)와 물리 ERD(테이블·컬럼·키·인덱스)를 모두 작성하고 일치 확인, PK·FK·관계 표시, 모든 컬럼의 타입·길이·제약조건·기본값·코멘트, NOT NULL·UNIQUE·CHECK·인덱스 적용 이유, 3NF 기준 중복 제거와 삽입·갱신·삭제 이상 확인.

### 발표 PPT 구성 (과제 기준)

1. 사용자·문제·서비스의 대표 사용 흐름
2. 최소 구현 범위와 백엔드·DB·UI 구성
3. API·화면·DB 설계의 주요 결정
4. 배포된 서비스와 로그 대시보드 동작
5. 사용자 피드백과 AI 답변 개선 전후
6. 확인한 오류·문제 해결·남은 한계·팀원별 기여

시연 순서: 사용자 화면의 입력·답변 → 저장된 기록 조회 → 운영 화면에서 같은 요청의 로그·지표 → 피드백 사례와 개선 전후 비교. 자세한 체크리스트는 `docs/DEMO_CHECKLIST.md`. 화면과 로그에 키·토큰·개인정보가 보이지 않게 한다.

### 협업 규칙 (과제 기준)

작업 등록(Issue) → 브랜치 작업 → PR → 다른 팀원 1명 확인 → 병합. 구체적 규칙은 저장소 루트의 `CLAUDE.md`.

## 2. 서비스: 집 보기 메모 비교

- 사용자: 월세·전세 집을 여러 곳 보러 다니는 사람.
- 불편: 집마다 적은 메모가 흩어져 있고 형식이 달라 비교가 어렵고, 꼭 물어봐야 할 항목을 놓친다.
- 해결: 메모를 입력하면 AI(Gemini, `gemini-3.5-flash-lite` 무료 등급)가 보증금·월세·관리비·장단점·체크리스트 9개 항목(채광·소음·수압·곰팡이·난방·층수·옵션·보안·교통)을 정해진 JSON으로 정리하고, 매물 비교표와 빠진 확인 항목을 보여 준다.
- 구성: 화면 Streamlit(`frontend/`) · 서버 FastAPI(`backend/`) · DB·인증·사진 Supabase · 초안·캐시·실시간 로그 Redis 호환 저장소.
- 배포: 서버 Render(`https://house-tour-notes-api.onrender.com`), 화면 Streamlit Community Cloud(`https://aio-03-p1-team3-xqmxzsnatycg7fxy9agfvg.streamlit.app/`). 무료 서버는 잠들어 있으면 첫 요청이 최대 1분 걸린다.
- 화면: 세션 목록 → 세션 상세(메모 입력·매물 지도·예산·항목 가중치·비교표·적합도 순위) → 매물 상세(분석 결과·수정·평가·사진·항목 만족도·위치) → 마이페이지(내 정보·내 사진·요약·가중치 프로필·내 발품 후기) / 발품 후기 쓰기·목록 / 동네 지도 탐색 / 운영자 전용: 운영 대시보드(실시간 로그·지표·피드백 목록), 개선 전후 비교.

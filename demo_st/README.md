# 동네 지도 탐색 — Streamlit

`demo1`의 FastAPI/HTML 데모를 Streamlit으로 옮긴 독립 실행 버전입니다.
원본 `demo1` 파일은 수정하지 않습니다.

## 실행

저장소 루트(`C:\aio-03-p1-team3`)에서 실행합니다.

```powershell
uv sync
uv run streamlit run demo_st/main.py
```

기본 접속 주소는 http://localhost:8501 입니다. 이미 사용 중인 포트라면
`--server.port 8502`를 추가하고 해당 주소를 카카오에도 등록하세요.

## 카카오 지도 설정

이 작업 환경에는 기존 `demo1`의 JavaScript 키를 `demo_st/.env`로 옮겨 두었습니다.
`.env`는 Git에서 제외되므로 다른 환경에서는 아래 방법으로 키를 설정하세요.

화면의 **카카오 지도 설정**에 기존 데모에서 사용하던 앱의 **JavaScript 키**를 입력합니다.
REST API 키가 아닌 JavaScript 키를 사용해야 합니다.
카카오 개발자 콘솔에서 카카오맵 사용 설정을 확인하고, Web 도메인에
`http://localhost:8501` 등 실제 접속 주소를 등록하세요.

키를 매번 입력하지 않으려면 다음 중 하나로 설정합니다.

- `demo_st/.env.example`을 `demo_st/.env`로 복사하고 키 입력
- 환경 변수 `KAKAO_JAVASCRIPT_KEY` 설정
- 저장소 루트의 `.streamlit/secrets.toml`에 아래 항목 추가

```toml
KAKAO_JAVASCRIPT_KEY = "YOUR_KAKAO_JAVASCRIPT_KEY"
```

JavaScript 키는 지도 SDK 로딩 과정에서 브라우저에 전달됩니다.
키를 바꾼 후 SDK 재로딩 안내가 표시되면 브라우저를 새로고침하세요.

## 기능

- 카카오 우편번호 서비스의 주소 검색창에서 도로명·지번·건물명 검색
- 사용자가 선택한 주소의 좌표를 변환해 지도 이동 및 마커 표시
- 선택한 주소의 우편번호·도로명주소·지번주소·건물명 확인
- 역 이름 검색 및 해당 역에 마커 표시
- 검색한 주소·역을 기준으로 반경 300m·500m·1km 안의 더미 매물을 가까운 순서로 조회
- 검색 기준 마커, 반경 원, 매물 마커 표시 및 마커 클릭 시 가격·거리 확인
- 매물 목록에서 가격·면적·층수 확인 및 매물 선택
- 목록 또는 지도 마커에서 선택하면 실제 도로명주소·지번주소·우편번호와 출처 확인
- 지도 드래그·확대·축소
- 지도 중심, 남서쪽, 북동쪽 좌표를 Streamlit 패널에 표시
- 서울 중심으로 돌아가기 및 검색 마커 제거
- 키 누락, 지도 로딩 실패, 검색 결과 없음 안내

**주소 검색** 버튼을 누르면 카카오 주소 검색창이 열립니다.
검색 결과에서 원하는 주소를 선택하면 검색창이 닫히고 지도가 해당 주소로 이동합니다.
주소 검색창은 별도 키 없이 동작합니다. 지도 표시와 주소 좌표 변환에는 기존 카카오 JavaScript 키를 사용합니다.

## 서울역 주변 더미 매물

`demo_st/data/listings.json`에 실제 주소와 건물 대표 좌표를 사용하는 샘플 9개가 들어 있습니다.
도로명주소·지번주소·우편번호·좌표는 공개 주소자료에서 확인했습니다.
가격·면적·층수·주택 유형·임대 조건은 가상이며 실제 거래나 임대 가능 여부를 나타내지 않습니다.
DB에 등록하지 않고 로컬 JSON을 조회합니다.

각 데이터에는 `road_address`, `parcel_address`, `postal_code`, `building_name`,
`address_source_url`, `address_verified_on`을 함께 저장했습니다(확인일: 2026-10-16).
좌표는 출처에서 제공하는 건물 대표 지점으로, 출입구나 개별 세대의 위치와 다를 수 있습니다.

앱은 처음에 서울역 데모 기준점(위도 37.5547, 경도 126.9706)을 기준으로 검색합니다.
**서울역 더미 매물 보기**를 누르면 언제든 이 기준점으로 돌아옵니다.

반경 선택 즉시 지도와 목록이 갱신됩니다. 주소나 역을 검색하면 그 위치가 새 검색 기준점이 됩니다.
검색 API가 반환하는 서울역 좌표는 데모 기준점과 다를 수 있어, 위 개수는 **서울역 더미 매물 보기** 기준입니다.
지도 드래그 또는 **지도에서 보기**는 검색 기준을 바꾸지 않습니다.
**서울 중심으로**는 검색 기준과 매물 표시를 초기화합니다.

거리 계산은 Python에서 좌표 간 구면 직선거리를 계산하며, 도보 이동 거리가 아닙니다.
지도 키가 없어도 반경별 매물 목록은 확인할 수 있습니다.
추후 DB 연결 시 `demo_st/listings.py`의 `search_listings()`를 DB 반경 조회로 교체할 수 있습니다.

지도는 Streamlit Custom Components v2로 카카오 JavaScript SDK를 연결합니다.
지도 이동 후 좌표가 Python으로 전달되며, Streamlit이 다시 실행되어도 지도 위치를 유지합니다.
이 데모는 로컬 JSON 데이터를 사용하므로 Docker나 FastAPI 서버를 실행할 필요가 없습니다.
